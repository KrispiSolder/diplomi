## Запуск (скриншот зелёного результата)

Из корня проекта:

```bash
php artisan test --configuration=phpunit.diploma.xml
```

Ожидаемый вывод: **6 passed** (зелёные галочки в терминале).

> Используется MySQL из `.env`. Тесты обёрнуты в транзакции: после прогона данные откатываются, основная БД не затирается.

## Если `could not find driver (sqlite)`

Стандартный `phpunit.xml` принудительно включает SQLite. Для диплома используйте **`phpunit.diploma.xml`** (команда выше).

## Ручная проверка в браузере (по желанию)

1. Регистрация: `/register` → новый email → проверить запись в таблице `users`.
2. Корзина: войти → карточка товара → «В корзину» → таблица `cart_items`.
3. Заказ: `/cart` → оформить с адресом и способом оплаты → `orders`, корзина пуста.
4. Негатив email: `/register` с `test@` без домена → ошибка под полем email.
5. User + admin: войти как `user@example.com` → открыть `/admin/dashboard` → 403.
6. Гость + delete: без входа отправить DELETE на `/admin/products/1` → редирект на `/login`.
