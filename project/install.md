Установка и запуск интернет-магазина
1.	В XAMPP запустить Apache и MySQL.
2.	Клонировать репозиторий проекта и скопировать папку
3.	Создать базу данных.
4.	Выполнить composer install, скопировать. env.example в. env, отредактировать .env, выполнить php artisan key:generate и php artisan storage:link.
5.	Выполнить npm install.
6.	Запустить php artisan serve.
7.	Запустить npm run dev.
8.	Открыть http://localhost:5173.
